
# hjiky Launcher

**Независимый лаунчер для Minecraft: Java Edition**

hjiky Launcher — сторонний лаунчер, предназначенный для установки, настройки и запуска Minecraft: Java Edition.

Проект предоставляет удобный интерфейс для управления версиями игры, настройки Java и использования различных загрузчиков модификаций.

## Возможности

- Авторизация через Microsoft Account.
- Выбор версий Minecraft, включая стабильные релизы и снапшоты.
- Поддержка Vanilla, Fabric, Forge и NeoForge.
- Установка и управление версиями игры.
- Настройка Java и выделяемой оперативной памяти.
- Управление Microsoft-аккаунтами.
- Настройка внешнего вида лаунчера.
- Журнал событий и консоль отладки.

## Системные требования

- Windows 10 / 11.
- Подключение к интернету.
- Учётная запись Microsoft.
- Лицензионная копия Minecraft: Java Edition.
- Java Runtime Environment (при необходимости).

## Установка

1. Перейдите в раздел [Releases](../../releases).
2. Скачайте последнюю версию лаунчера.
3. перенесите в отдельную папку.
4. Запустите `hjiky Launcher.exe`.
5. Авторизуйтесь через Microsoft.
6. Выберите версию игры и необходимые настройки.
7. Запустите Minecraft.

## Важно: расположение лаунчера

Запускайте `hjiky Launcher.exe` непосредственно из папки, в которой он находится.

Файлы Minecraft, игровые версии и другие необходимые данные лаунчера будут храниться в этой же папке или в её подкаталогах.

Не перемещайте EXE-файл отдельно от папки с игровыми данными, чтобы избежать проблем с поиском файлов и запуском игры.

Рекомендуется создать отдельную папку для лаунчера и запускать его именно из неё.

## Авторизация

Для входа используется Microsoft OAuth. Взаимодействие с игровыми сервисами осуществляется через механизмы авторизации Microsoft и Minecraft.

Для использования игровых сервисов может потребоваться одобрение Application ID.

## Статус проекта

Проект находится в разработке. Возможны ошибки, изменения и добавление новых функций.

## Отказ от ответственности

hjiky Launcher — независимый проект сообщества. Он не связан с Microsoft, Mojang Studios или Xbox и не является официальным продуктом этих компаний.

Для использования лаунчера требуется собственная лицензия Minecraft: Java Edition.

# hjiky Launcher (English)

**An independent launcher for Minecraft: Java Edition**

hjiky Launcher is a third-party launcher designed to install, configure, and launch Minecraft: Java Edition.

The project provides a convenient interface for managing game versions, configuring Java, and using various mod loaders.

## Features

- Microsoft Account authentication.
- Minecraft version selection, including stable releases and snapshots.
- Support for Vanilla, Fabric, Forge, and NeoForge.
- Game installation and version management.
- Java configuration and RAM allocation.
- Microsoft account management.
- Launcher appearance customization.
- Event logs and debugging console.

## System Requirements

- Windows 10 / 11.
- Internet connection.
- Microsoft account.
- A legitimate copy of Minecraft: Java Edition.
- Java Runtime Environment, if required.

## Installation

1. Go to the [Releases](../../releases) section.
2. Download the latest launcher version.
3. Extract the archive into a separate folder, if downloaded as an archive.
4. Run `hjiky Launcher.exe`.
5. Sign in with your Microsoft account.
6. Select a game version and configure your settings.
7. Launch Minecraft.

## Important: Launcher Location

Run `hjiky Launcher.exe` directly from the folder where it is located.

Minecraft files, game versions, and other required launcher data will be stored in the same folder or its subdirectories.

Do not move the EXE file separately from the game data folder, as this may cause file detection and game launching issues.

It is recommended to create a dedicated folder for the launcher and always run it from that location.

## Authentication

The launcher uses Microsoft OAuth for authentication. Interaction with game services relies on Microsoft and Minecraft authentication mechanisms.

Approval of the Application ID may be required to access certain game services.

## Project Status

The project is currently under development. Bugs, changes, and new features may be introduced.

## Disclaimer

hjiky Launcher is an independent community project. It is not affiliated with, endorsed by, or officially associated with Microsoft, Mojang Studios, or Xbox.

A legitimate Minecraft: Java Edition license is required to use the launcher.
